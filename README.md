# IOE Admission Hub

**Website:** [https://ioe-admission.dipeshsapkota7.com.np/](https://ioe-admission.dipeshsapkota7.com.np/)

A complete admission toolkit for IOE engineering applicants. Features statistical rank predictions, automated priority form generation, financial analytics, and step-by-step counseling guides.

## 🚀 Core Features

* **Statistical Rank Predictor:** Algorithmically estimates expected IOE entrance ranks based on historical cutoff data and admission trends.
* **Priority Form Generator:** Automates the creation and structuring of college/program priority lists for official submission.
* **CBT Score Estimator:** Calculates expected scores for the Computer-Based Examination.
* **Financial & Cutoff Analytics:** Breaks down 4-year fee structures across constituent and affiliated engineering colleges.
* **Step-by-Step Counseling Guides:** Provides a structured roadmap for the entire physical admission procedure, document verification, and deadlines.

## 💻 Tech Stack

* **Framework:** React.js powered by Vite
* **Styling:** Tailwind CSS
* **Deployment & Hosting:** Vercel
* **SEO & Performance:** Fully optimized with custom JSON-LD schemas, dynamic XML sitemaps, and WebP asset delivery.
